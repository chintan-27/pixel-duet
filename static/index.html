The Process

01

Map Colors

Every pixel in Image A is converted to CIELAB color space. A multiscale coarse-to-fine assignment uses the Hungarian algorithm to find the optimal bijective mapping to Image B's structure.

02

Merge + Refine

Overlapping tile windows are merged via cost-aware swaps that preserve the bijection. Local pairwise refinement passes smooth seams and eliminate visible block artifacts.

03

Animate

Each pixel travels along a cubic Bézier path with configurable easing and staggered start times. Choose from 6 easing modes. Rendered to GIF, MP4, or WebM.

Pixel Duet

An open-source tool for bijective pixel rearrangement. Built with NumPy, SciPy, Matplotlib, and FastAPI. Every pixel from Image A ends up somewhere in Image B — nothing added, nothing lost.
